#Git Cheat Sheet

## Getting started
start a new repo:

```
git init 
```
clone existing repo:

```
git clone <url>
```


## Prepare to Commit

Add untracked file or unstaged changes:
```
git add <file>
```

Add all untracked files and unstaged changes:
```git add .
``` 


## Useful commands
List files seen by git:
```
git ls-files
```
